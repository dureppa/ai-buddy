# AI Buddy

Прототип помощника для стажёров Авито. В веб-сервисе стажёр сможет следить за онбордингом, общаться с Buddy и получать напоминания. Браузерное расширение даст быстрый доступ к Buddy и позволит задать вопрос о текущей странице.

В репозитории есть каркас, документация и зафиксированные зависимости. Текущий пользовательский прототип реализуется только во фронтенде. Для него используй `npm ci` из корня, затем `npm run dev --workspace=@ai-buddy/web`. Demo-adapter хранит прогресс, заявки и ответы Buddy в `localStorage`, поэтому веб-приложение можно показать без Go и Python сервисов. Версии инструментов и локальное окружение описаны в [стеке проекта](docs/stack.md). Backend и AI-контракты остаются в документации до отдельной задачи.

## Фронтенд

```bash
npm ci
npm run dev --workspace=@ai-buddy/web
```

Открой `http://localhost:5173/`. Переключение между демонстрационными профилями находится в меню профиля. Расширение собирается командой `npm run build --workspace=@ai-buddy/extension`, после чего каталог `apps/extension/dist/` можно загрузить в Chromium как unpacked extension. После установки питомец появляется справа внизу на обычных веб-страницах, а при наведении показывает действие «Задать вопрос». Chrome запрашивает доступ к сайтам при установке расширения один раз.

Полный локальный набор проверок запускается командой `just check`. Отдельные проверки frontend, Python и Go доступны через `just frontend-check`, `just python-check` и `just go-check`.
