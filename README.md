# AI Buddy

Прототип помощника для стажёров Авито. В веб-сервисе стажёр сможет следить за онбордингом, общаться с Buddy и получать напоминания. Браузерное расширение даст быстрый доступ к Buddy и позволит задать вопрос о текущей странице.

В репозитории есть каркас, документация и зафиксированные зависимости. Для установки используй `npm ci` из корня, `uv sync --locked` из `services/ai-python/` и `go mod download` из `services/backend-go/`. Версии инструментов и локальное окружение описаны в [стеке проекта](docs/stack.md). Команды запуска появятся вместе с реализацией сервисов.
