# Локальный Python MCP-сервер

Авторизован 13.11.2026. Развиваем Python MCP отдельно от Flask; Go и UI не меняются. Go HTTP-адаптер из инструкции ещё не реализуется. Локальные данные не являются правилами Авито.

Сервер MUST запускаться отдельным ASGI-процессом только на loopback и только при явном MCP_DEMO_ENABLED=true, заданном MCP_DEMO_TOKEN и выбранном существующем demo profile. Никакого автоматического fallback при недоступном Go. GET /health/live сообщает режим demo, не проверяет LLM.

POST /mcp MUST использовать SDK Streamable HTTP, stateless/json_response, проверять Host/Origin и bearer до handshake/discovery/call. Контекст профиля из конфигурации/token binding, не из аргументов LLM; параллельные запросы не смешивают субъектов. Demo-токен — локальный секрет, не реализация будущего Go resolve/audience flow. Тело ≤64 KiB, tool result ≤32 KiB.

Каталог MUST содержать только search_knowledge и get_team_context с точными существующими CONTRACTS schemas. Аргументы/результаты закрыты, лишние поля отвергаются; поиск нормализует пробелы, соблюдает limit 1–5, возвращает только соответствующие запросу учебные документы либо []. Пустой контекст не заменяется выдуманным контактом. Инструменты не пишут данные.

Данные MUST быть отдельным версионированным JSON-корпусом с source/version/is_demo, не gold labels. Backend-интерфейс допускает test fixtures, но приложение не импортирует evals/experiments. Ошибки, неверные результаты и timeout дают безопасный error envelope без exception/body/token. Вызов backend ограничен 4 с; весь MCP-ход клиента остаётся ≤5 с. Превышение результата даёт RESULT_TOO_LARGE, timeout — MCP_TIMEOUT; клиент должен сохранять эти безопасные коды.

Проверки MUST включать настоящий SDK client/server протокол, авторизацию до данных, точные schemas, обе функции, пустой поиск, лимиты/неверные args, ошибки/таймауты/размеры, Host/Origin и конкурентную изоляцию профилей. Live LLM отдельно; прохождение контрактов не доказывает качество ответов.
