# Flask + прямой локальный агент

Область: Python, OpenSpec и описание Python-компонента. Go/UI и публичный API не меняются. Текущая ветка сохраняется по политике пользователя о логических блоках.

## Поведение

- `AI_AGENT_ENABLED=true` и заданный `OLLAMA_MODEL` MUST подключать реальный прямой runner к существующему POST /internal/v1/turns. Без явного включения сохраняется 503, fake/demo не включается. Адрес Ollama — только настроенный loopback URL; model/url/token не берутся из пользовательского текста.
- Runtime MUST использовать общий с экспериментом прямой цикл, prompt и политику источников из ai_buddy; runtime MUST NOT импортировать experiments, LangChain или LangGraph. История user/assistant используется только как история, не как реестр доказательств. URL страницы передаётся как непроверенный контекст без загрузки сайта и без утверждения о DOM.
- Одна MCP-сессия и один HTTP-клиент Ollama создаются на ход и закрываются в том же event loop. MCP остаётся реальным SDK Streamable HTTP. Allowlist по-прежнему только search_knowledge/get_team_context; несовместимые схемы не обходятся.
- Лимиты MUST сохраняться: 25 с весь ход, 20 с по умолчанию на модель, 5 с MCP, 3 модельных вызова, 6 tool-попыток; одна корректировка цитаты в том же бюджете. Пакет tools больше остатка бюджета отклоняется до исполнения. Автоматических сетевых повторов нет.
- Ollama MUST вызываться stream=false, think=false, temperature=0, seed=42, num_ctx=4096, num_predict=384. Ответ/аргументы MUST валидироваться; незавершённая генерация, неверная роль/структура, пустой текст и превышение размера не публикуются. Размер JSON-запроса и ответа ограничивается 64 KiB; вход не обрезается кодом. Это лимит байтов, не гарантия токенизации/отсутствия внутреннего усечения контекста Ollama.
- Таймаут модели/общего хода MUST давать 503/AI_TIMEOUT, сеть/недоступная модель/5xx/ошибка авторизации — 503/AI_UNAVAILABLE, 429 — AI_RATE_LIMITED, некорректный ответ — AI_INVALID_RESPONSE. Технический/ACL-сбой MCP MUST завершать runtime с безопасным исходным кодом, без выдуманного успеха. Недоверенный документ/пустые знания — безопасный содержательный ответ 200.
- Ответ MUST содержать только исходные request_id/conversation_id и Reply{text,references}; references строятся кодом из реально процитированных допущенных источников. Сырые ответы, черновики, токены и tool output не включаются в HTTP/логи. Диагностика содержит только request-id, модель, версию prompt, счётчики, длительность и безопасный код.
- Readiness MUST проверять только локальную конфигурацию, без генерации и сетевых запросов. 200 не обещает доступность Ollama/MCP. Установленная модель и совместимый внешний MCP обязательны для live-выполнения; Python-функции тестового сервера не подменяют Go.

## Необходимые проверки

Flask → настоящий DirectRunner → подмена HTTP Ollama / MCP: ответ и references, история без секретов, локальная конфигурация/включение, сетевые/HTTP/структурные ошибки LLM, model/turn/MCP timeout с cleanup, лимит tools до первого эффекта, последовательные независимые ходы. Уже существующие тесты входа, ACL, схем, политики и изоляции не дублируются. Общий Python coverage >80% (локальный gate 85%) включает runtime и experiments; тесты/зависимости исключены.

Live-smoke MUST отдельно показать Flask + установленную Qwen + настоящий MCP-протокол на синтетическом сервере. Это не подтверждает ещё не реализованный Go → Python/MCP или полный онбординг. Оценка знаний, evidence, шесть корпоративных tools, решение наставника и переходы остаются вне этого блока.
