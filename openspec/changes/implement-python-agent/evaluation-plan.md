## Набор

A-05 заменяет прежнюю предложенную цель 60 кейсов/три повтора: стартовый набор 20 development и 10 holdout по независимым семействам. Это изменение предложенного объёма, не ослабление требований ТЗ. Все сценарии безопасности проверяются детерминированно независимо от размера живого набора. P0 — ноль нарушений; прочие результаты публикуются как измерения, а не обещание общего качества. Порог качества для выпуска согласовать после development и до holdout; не подбирать его по holdout.

Кейс хранит case_id, requirement/scenario ids, профиль/этап/права, версии корпуса/рубрики, вопрос/ответ, ожидаемые факты, допустимые и запрещённые calls/arguments, ожидаемые побочные эффекты и состояние Go. Текст не обязан совпадать дословно. Включить по одному позитивному и негативному семейству для каждой из шести категорий и отдельно смешанные trainee/mentor пункты, несуществующий регламент и legacy API.

## Метрики

Отдельно измерять: обоснованность ответа, корректность выбора и аргументов инструментов, отсутствие запрещённых эффектов, совпадение оценки с заранее размеченной рубрикой, ошибки/таймауты, длительность и usage/cost при известном тарифе. Отказы по правам и недостаток данных считаются успешным поведением в соответствующих кейсах. Зафиксировать model/prompt/corpus и размеры выборок; holdout не включать в prompts. LLM-as-judge не является единственным проверяющим самого агента: эталоны и ручной разбор остаются необходимыми.

## Тесты и демонстрация

Unit/Flask-contract — fake LLM/clock/MCP без внешней сети; integration — реальный протокол локального MCP; system — Go/UI/mock с явным подтверждением и review; live eval — отдельная платная команда после реализации. Coverage считает весь прикладной пакет, включая error paths, без тестов/зависимостей/генерации. Python 85% — наш gate, общее покрытие прикладного кода команды должно превышать 80%.

Главный demo: найти задачу CL → открыть учебное согласие → пользователь подтверждает в сервисе → MCP читает сохранённое evidence → агент готовит сводку/предусмотренную проверку знаний → наставник одобряет → Go открывает следующий этап → перезагрузка сохраняет результат. Негативные маршруты: отказ по правам, изменение версии после оценки, недоступность сервиса, повтор решения и неизвестный итог записи. Факт просмотра документа/красивый ответ не заменяют критерий задачи.
