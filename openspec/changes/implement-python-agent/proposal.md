# Proposal

## Why

Агент должен работать с онбордингом по предоставленному чек-листу и только шестью выбранными корпоративными сервисами. Прежний основной маршрут с заявкой на доступ заменён этим целевым поведением. Спецификации обновлены; затем авторизован первый Python-срез Flask/MCP/tests. Go/UI и публичный OpenAPI не меняются.

## What Changes

- Онбординг описывается в разделе агента: контекст задания, источник, роль исполнителя, период, доказательства, оценка и следующий шаг.
- Корпоративная область ограничена отсутствиями, командировками, наймом, увольнениями, согласиями и бенефитами. Чек-лист — процесс AI Buddy, а не седьмой корпоративный сервис.
- Агент оценивает знания и готовит рекомендацию; наставник одобряет; Go проверяет условия и применяет переход.
- Добавлены [проверенные источники и допущения](sources-and-assumptions.md), [контракты MCP](mcp-contracts.md), [дизайн](design.md), [проверки](evaluation-plan.md) и [план](tasks.md).
- API шести моков предоставляет Go-разработчик, интерфейсы — фронтенд-разработчик. Их готовность этим документом не подтверждается.

## Capabilities

### New Capabilities

- `agent-behavior`: сопровождение онбординга, источники, оценка и границы полномочий.
- `mcp-tools`: проверяемое взаимодействие с заданиями и шестью сервисами.
- `python-ai-service`: доверенный вход Go, ограниченный цикл LLM/MCP, изоляция и сбои.
- `agent-evaluation`: тесты сервиса и оценка поведения модели.

### Modified Capabilities

Нет опубликованных baseline-спецификаций в openspec/specs. Обновляется ещё не реализованное предложение, а не отчёт о внедрении.

## Impact

Документы агента и ограниченный Python-срез (foundation-scope.md). Контракты Go/UI требуют отдельного согласования до реализации; текущий contracts/openapi.yaml не описывает новые оценки, этапы и корпоративные черновики. Старые access-инструменты и формат AccessRequestDraft не переиспользуются для других сервисов без явного изменения API. Ранее предложенные LMS, календарь, IT-сервис, выдача доступа к репозиторию и автоматический переход агента исключены из нового каталога. Исторические SDD и существующие API сохраняются как baseline, а не целевая приёмка этого изменения.
