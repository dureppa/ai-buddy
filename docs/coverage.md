# Отчёт о покрытии

Дата последнего прогона веба: 16 ноября 2026. Даты остальных контуров сохранены ниже; в исправлении карточки отметки переизмерены веб и Python.

Порог кейса — больше 80% строк прикладного кода, написанного командой. Зависимости, сгенерированный код и сами тесты в измерение не входят. Проценты контуров не складываются и не усредняются. Имитации корпоративных систем в `corporate-services/` и `tools/` в этот порог не входят: так организаторы ответили на вопрос о моках. Go встроенным инструментом считает покрытие операторов, не строк. В отчёте это названо прямо.

Сырые `web/coverage/`, `coverage.out` и `.coverage` в git не коммитятся. Повтори команды ниже, чтобы получить те же отчёты локально.

```bash
npm run test:coverage --workspace=@ai-buddy/web
```

Локально команда выполнена на Node 24.22.2. CI берёт Node 24.22.2 из `.nvmrc` и ту же команду. Отчёт LCOV пишется в `web/coverage/lcov.info`, в CI он сохраняется артефактом `web-coverage`.

Последний веб-прогон дополнительно проверяет скрытую карточку при входе и обычном вопросе, показ после вопроса о задании и исчезновение через две секунды после успешной отметки.

Полный `just check` прошёл. В браузере локального демостенда проверены кнопка, сообщение «ознакомился», повтор «готово» и сохранённые checkbox после reload.

## Go API

Дата прогона этого контура: 15 ноября 2026.

Команда из `web/backend` после применения `migrations/*.up.sql` и `seeds/demo.sql` к пустой базе, как в CI:

```bash
TEST_DATABASE_URL=postgres://$USER@127.0.0.1:5432/aibuddy_test?sslmode=disable \
  go test -coverprofile=coverage.out -covermode=atomic ./...
go tool cover -func=coverage.out
```

Инструмент: `go test -covermode=atomic`, покрытие операторов. Go 1.26.11. Последний прогон выполнен 16 ноября 2026 локально на отдельной PostgreSQL 16.15 после применения всех миграций и демоданных, поверх main `d7d13b4` с исправлением рабочих инструментов. Рабочие базы не использовались. CI использует PostgreSQL 17. Без `TEST_DATABASE_URL` тесты с PostgreSQL пропускаются.

Прогон использует PostgreSQL и локальные HTTP-заглушки для внешних сервисов.

Исправление рабочих инструментов проверено полным Go API с `go vet`, `go test -race -count=1 ./...` и atomic coverage: 451 тест/подтест прошёл, пропусков нет. `service-go-check` прошёл для всех внешних модулей с PostgreSQL и race. Показатели Python и веба в этом изменении не переизмерялись; 242 веб-теста, 10 тестов расширения и 58 тестов сайтов сервисов прошли без измерения покрытия.

Chrome проверил все 52 перехода из карточек с настоящим локальным Go API и PostgreSQL. Самостоятельные HTTP-обработчики проверены Go-тестами для той же матрицы. Полный `just check` остановился на отсутствии `just`; Go и frontend-проверки выполнены напрямую. Python и Docker/external-check в этом изменении локально не запускались.
