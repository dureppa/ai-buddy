# Отчёт о покрытии

Дата прогона: 15 ноября 2026.

Порог кейса — больше 80% строк прикладного кода, написанного командой. Зависимости, сгенерированный код и сами тесты в измерение не входят. Проценты контуров не складываются и не усредняются. Имитации корпоративных систем в `corporate-services/` и `tools/` в этот порог не входят: так организаторы ответили на вопрос о моках. Расширение собирается и тестируется в `just frontend-check`, в таблицу ниже не включено.

Go встроенным инструментом считает покрытие операторов, не строк. В отчёте это названо прямо.

Сырые `web/coverage/`, `coverage.out` и `.coverage` в git не коммитятся. Повтори команды ниже, чтобы получить те же отчёты локально.

## Веб Buddy

Команда из корня:

```bash
npm run test:coverage --workspace=@ai-buddy/web
```

Инструмент: Vitest и V8, покрытие строк файлов `web/frontend/src`, без `*.test.*` и `*.d.ts`. Порог скрипта — 85% строк.

| | |
| --- | --- |
| Тесты | 242, все прошли |
| Строки | 91,37% (1504 из 1646) |
| Операторы | 89,10% (1685 из 1891) |

Локально команда выполнена на Node 24.22.2. CI берёт Node 24.22.2 из `.nvmrc` и ту же команду. Отчёт LCOV пишется в `web/coverage/lcov.info`, в CI он сохраняется артефактом `web-coverage`.

Последний веб-прогон проверяет доступ к настройкам через кнопку «Профиль» и форму вопроса в боковом меню. Полный `just check` прошёл на совместной версии PR #78 и #83 с main b6580ad: 658 Python-тестов, 229 веб-тестов, 10 тестов расширения и 58 тестов сайтов сервисов, Go vet/test, repository и Compose. После исправления относительных ссылок внешней панели повторно прошли `just frontend-check` (241 веб-тест), покрытие, repository и Compose; Python/Go этим дополнением не менялись. Локальные Go-тесты без PostgreSQL пропускают DB-интеграции; они оставлены CI. Для изменённого пакета `internal/ai` отдельно измерено 81,3% операторов; это не общий процент Go API и не заменяет приведённый ниже прогон с БД. Python и внешние сервисы этим блоком не менялись.

## Go API

Команда из `web/backend` после применения `migrations/*.up.sql` и `seeds/demo.sql` к пустой базе, как в CI:

```bash
TEST_DATABASE_URL=postgres://$USER@127.0.0.1:5432/aibuddy_test?sslmode=disable \
  go test -coverprofile=coverage.out -covermode=atomic ./...
go tool cover -func=coverage.out
```

Инструмент: `go test -covermode=atomic`, покрытие операторов. Версия Go — 1.26.11. Прогон выполнен на сервере с отдельной временной PostgreSQL 17, всеми миграциями и seed; контейнер удалён после измерения. Рабочие базы не использовались.
