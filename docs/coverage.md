## Веб Buddy

Из корня: `npm run test:coverage --workspace=@ai-buddy/web`.
Vitest/V8 измеряет `web/frontend/src`, исключая `*.test.*` и `*.d.ts`.
Прогон выполнен локально на Node 24.22.2, порог команды — 85% строк.
Настройка Vitest отключает встроенный Web Storage в тестовых процессах,
чтобы браузерные тесты использовали хранилище jsdom.

| Показатель | Результат |
| --- | --- |
| Тесты | 325, все прошли |
| Строки | 92,47% (1709 из 1848) |
| Операторы | 90,56% (1930 из 2131) |

Добавлены проверки серверного чтения/изменения/удаления календаря, переноса
старых и пустых записей, ошибок API, сохранения исходного ключа при ошибке,
приоритета текущего профиля, карточки создания и ссылки `/events`. UI-тест
моделирует потерю ответа после записи: повтор использует тот же ID и не
создаёт второй экземпляр. Старый локальный режим также проверяется.

Проверены одинаковый контекст кнопки «С чего начать сегодня?» и текста
«какая задача сейчас?», переход от старого выбранного пункта к текущему
для четырёх профилей и сохранение выбранного пункта для уточнения «этот пункт».
Вопросы не меняют отметки выполнения. Полный frontend-check также проверяет расширение
(10 тестов) и сайты сервисов (58 тестов), типы, формат, lint и сборки.
Эти два набора не включены в процент веба Buddy.

Проверки подсказок покрывают старт, активный пункт, переход между группами,
завершение плана, отсутствие данных и сбой API. UI-тесты сверяют оба списка
и проверяют их обновление после отметки задания и подтверждения анкеты.

## Go API

Go 1.26.11 и PostgreSQL 17 из закреплённых образов Docker. На пустой тестовой
БД применены все `migrations/*.up.sql` и `seeds/demo.sql`. Подставь адрес этой
БД в переменную `TEST_DATABASE_URL` и запусти из `web/backend`:

```bash
go test -race -count=1 ./...
go test -count=1 -coverprofile=coverage.out -covermode=atomic ./...
go tool cover -func=coverage.out
go run ../../ops/checks/go-coverage-lines.go coverage.out github.com/dureppa/ai-buddy/web/backend
```

**Строки Go — 90,71% (3086 из 3402).** Скрипт сопоставляет координаты
блоков из профиля с токенами исходника. В знаменателе уникальные строки,
где начинается токен внутри блока с операторами, без строк из одних
комментариев или разделителей. Строка покрыта, если хотя бы один её токен
принадлежит выполненному блоку. Если на одной строке несколько веток,
достаточно исполнения одной из них. Данные для расчёта ограничены файлами и
блоками из профиля.

Пакеты Go прошли без пропусков PostgreSQL-проверок. Проверены все шаблоны каталога через
HTTP-клиент, разрешённые каталоги четырёх профилей и BI `delivery-bi`.
Подготовка/открытие ничего не отправляют; чужой профиль и отозванный ресурс
отклоняются. Реальный PostgreSQL проверяет подтверждение BI, шесть параллельных
подтверждений, один сохранённый номер, повтор и отмену. Отдельный тест проверяет,
что поиск по «Компасу» находит два источника для Ольги и один для Александра.

Календарь: границы недели по Москве, смена года/високосная дата, включительные
даты и лимит 366 дней; SQL-фильтрация и сортировка, начальные записи один раз,
импорт из разных браузеров, пустой календарь, приоритет серверных изменений
и удалений, ограничение 500 активных событий. Проверены подготовка без записи,
подтверждение в PostgreSQL, отсутствие дубля, отмена/TTL/чужой профиль,
ограничение MCP-ответа 12 KiB. Настоящий HTTP сервер проверяет вход, PUT/GET/DELETE
личного календаря; общий race-прогон прошёл.

## Общий прогон

Проверки `fix/case-acceptance` выполнены по частям. `just frontend-check`,
`just repository-check` и `just compose-check` прошли на хосте, покрытие веба
проверено отдельно на закреплённом Node. `just python-check` прошёл в чистой
временной venv. Go vet, тесты, race и покрытие веб-API выполнены в Go-контейнере
с отдельной PostgreSQL. Внешние Go-модули прошли `ops/checks/service-go.sh`.

Учебные сервисы в `corporate-services/` и `tools/` не входят в показатели
прикладного Go API. Браузерный замер описан в [отчёте по интерфейсу](ui-responsiveness.md).

В последующем исправлении подтверждений повторены полный `python-check`,
`repository-check` и `compose-check`; полный набор Go/frontend не повторялся.
