# Архитектура AI Buddy

Стажёр работает в вебе. Go проверяет сессию и права, хранит диалог и черновики действий. Flask вызывает DeepSeek и Python MCP. MCP читает Go, а Go ходит в учебные API сервисов. Модель не записывает данные. Ссылка из ответа открывает `/actions/:id`, и только подтверждение человека отправляет одну попытку в сервис. Сейчас у агента до 13 инструментов, включая чтение рабочих инструментов направления.

Подробности действий: [service-actions](components/service-actions.md). Ответы на критерии кейса: [criteria](criteria.md).

| Компонент | Ответственность |
| --- | --- |
| [Веб](components/web.md) | Чат, чек-лист, кабинет наставника, страница подтверждения |
| [Расширение](components/extension.md) | Вопрос с контекстом страницы и переход в веб |
| [Go API](components/backend-go.md) | Сессия, права, диалог, черновики, вызов Flask и сервисов |
| [Python](components/ai-python.md) | Контекст запроса, DeepSeek, выбор инструментов, безопасные ошибки |
| [MCP](components/python-mcp.md) | Чтения и подготовка черновика по делегированному токену |
| Корпоративные сервисы и инструменты | Собственные процессы и базы. Buddy открывает их в браузере и читает через HTTP |

В Compose модель задаётся так: `AI_LLM_PROVIDER=deepseek`, модель `deepseek-flash`. MCP работает в режиме `go_http` и ходит в `http://go:8080`.

Чтения и подготовка черновика покрывают найм, увольнения, бенефиты и Jira. Отдельно агент читает команду, базу знаний, прогресс, каталог доступов, страницы Confluence и рабочие инструменты направления. Запись после подтверждения делает Go, не модель. Схемы — в `contracts/agent-tools.json`, поведение инструментов направления — в [SDD 009](specs/009-agent-role-tools.md).

Отметка чек-листа и публикации наставника в текущем вебе сохраняются в браузере. Диалог, черновик действия и результат подтверждения сохраняются на сервере.

Данные демонстрационные. Проверка прав — на каждом чтении и перед отправкой действия. Нет права или сервис не запущен — объяснение без записи. Заявка на доступ не выдаёт настоящие права: статус заявки не означает выданный доступ.

«[Уточнить у агента](specs/010-selection-explanation.md)» передаёт только выбранный
текст и ограниченный контекст задачи/записи. Связанные материалы читаются через
прежние MCP-инструменты с ACL. Подписанный режим read_only запрещает запись
через MCP, а локальные пункты чек-листа не объявляются серверным прогрессом.
