# Отзывчивость интерфейса

Замер 16 ноября 2026 года на локальном Docker Compose, веб в режиме с API.
Профиль Ольги Соколовой, macOS 15.6.1 arm64, Chromium 156.0.8078.4 headless,
окно 1440 × 900. Загрузка приложения и вход выполнены до замеров. На каждое
действие два разогрева и 20 зачётных повторов.

Время мерилось через `performance.now()` с момента события `click` до второго
кадра `requestAnimationFrame`, на котором наблюдался нужный элемент. Результат
перехода — видимый заголовок страницы. Результат отметки — видимый статус
«Выполнено» у задачи. Результат отправки вопроса — видимый индикатор «Buddy думает».
Для последнего браузер возвращал тестовый HTTP-ответ через 300 мс, чтобы
индикатор оставался видимым до фиксации кадра. Полное время генерации
модели в замер не входит. p95 — 19-е по порядку измерение из 20.

| Действие | Медиана, мс | p95, мс | Максимум, мс | Меньше 1 с |
| --- | ---: | ---: | ---: | ---: |
| Главная → Моя адаптация | 47,4 | 48,4 | 48,5 | 20/20 |
| Отметить пункт «Принципы продуктовой аналитики» | 30,8 | 31,7 | 32,5 | 20/20 |
| Отправить вопрос → увидеть «Buddy думает» | 30,4 | 31,5 | 31,7 | 20/20 |

Для повторения войди под Ольгой, открой «Главную», затем «Мою адаптацию».
Перед повтором чек-листа верни пункт в план. Для чата отправь «Кто мой
наставник?» и дождись исчезновения индикатора перед следующим повтором.
