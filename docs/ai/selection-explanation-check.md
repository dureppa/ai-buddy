## Автоматические проверки

- `just frontend-check`: формат, lint, типы, тесты трёх workspaces и сборки.
- `npm run test:coverage --workspace=@ai-buddy/web`: 226 passed,
  90,90% строк; BuddyPanel — 100% строк.
- `just python-check`: Ruff, mypy, 658 passed, 91,46% строк.
- `just repository-check`, `just compose-check`, `git diff --check`.
- Полный `just check` локально остановился на отсутствии gofmt/Go.
  Go-код не менялся. Go vet/test/race и DB-интеграции выполняет обязательный CI.

Проверены передача точного пункта, контекст в каждом уточнении, повтор без
дублирования реплики, смена пункта и общего режима, материалы Confluence,
переход в полный чат с общей историей и защита от позднего ответа другого
профиля. Python проверяет чтение команды и каталога инструментов, исключение
write-tools и недопустимость серверного task_id из локального пункта.

## Браузер

Chromium: 1440×1000 и 390×844, синтетические HTTP-ответы. Проверены панель
без смены страницы/отметки, карточка реального URL источника, контекст уточнения,
полный чат и общая история, снятие контекста, оба общих входа, повтор ошибки,
узкий экран без горизонтального скролла и переход из native dialog пункта.
Ошибок JavaScript нет. Отдельного UI выделения больше нет.

Это проверка интерфейса с подменённым HTTP и автоматические MCP/LLM-моки.
Новых платных вызовов DeepSeek в этой задаче не было. Ответы прежней проверки
выделения не доказывают качество нового пользовательского сценария. Семантическое
качество живой LLM и продуктовый эффект этими проверками не измерены.
