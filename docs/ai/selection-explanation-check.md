# Проверка «Уточнить у агента»

15 ноября 2026. SDD 010, ветка feature/ask-agent-selection.

## Автоматические проверки

- `just frontend-check`: Prettier, ESLint, TypeScript, тесты всех трёх workspaces
  и сборки Buddy, расширения и внешних сайтов — успешно.
- `npm run test:coverage --workspace=@ai-buddy/web`: 185 passed, строки 89,47%.
- `just python-check`: Ruff, mypy, 639 passed, строки 91,41%.
- Go 1.26.11: `go vet ./...`, `go test -coverprofile=coverage.out -covermode=atomic ./...`
  с отдельной временной PostgreSQL 17, миграциями и seed — успешно. Общий итог
  77,4% операторов; существующий общий порог Go >80% пока не закрыт.
- `just repository-check`, `just compose-check`, `git diff --check` — успешно.
- `just check` локально остановился на отсутствии Go; race и полный CI идут
  в обязательных jobs. Новые тесты автоматически подхватываются этими jobs.

На сервере отдельный временный nginx проверил семь маршрутов /buddy-api и
native API Confluence, доступов и рабочих инструментов. Проверялись 401/404
без чтения закрытых данных; рабочая nginx-конфигурация не менялась.
Тестовые PostgreSQL/nginx контейнеры удалены. Рабочие базы не использовались.

## Браузер

Chromium: карточка задачи с native dialog, сохранение фрагмента, контекст задачи,
панель у края окна, Escape без закрытия исходной карточки, страница Confluence,
мобильная ширина 390 px, уточнение в прежнем диалоге и отсутствие повторной
кнопки для открытого фрагмента. Восемь проверок, три синтетических HTTP-ответа,
ошибок JavaScript нет. Проверка нашла обрезание панели внутри dialog; исправлено
размещением через Popover API и проверено повторно. Это проверка UI с подменённым
HTTP, не сквозной прогон работающего Go/LLM на сервере.

## DeepSeek

Всего использованы 9 разрешённых платных запросов (6 + 3). Production transport
и DirectRunner/прямой цикл работают с синтетической MCP session, без настоящих
бизнес-действий. Проверены общий термин p95 из локального пункта, Confluence,
уточнение в диалоге, запись Redash и задача Jira. Все полученные ответы прошли
структурные guards; это не доказательство смысловой точности каждого факта.

Первый ответ Jira добавлял совет обратиться к наставнику из-за пустого поиска,
хотя сама задача уже содержала нужные данные. Промпт уточнён; пустой
вспомогательный поиск остаётся в аудите и исключается из контекста модели.
Последний запрос на итоговом коде вернул три коротких пункта по данным Jira,
без наставника и отчёта о пустом Confluence. Остальные сценарии после этой
последней правки повторно живой LLM не прогонялись. Общие объяснения терминов
не заменяют корпоративные инструкции. Качество holdout и продуктовый эффект
этим небольшим прогоном не измерены.
