# Проверка инструментов направлений

Дата: 15 ноября 2026. Ветка: feature/agent-role-tools.

## Автоматические проверки

- `just python-check`: Ruff, mypy, 603 теста, покрытие 91.19%, включая новые MCP-контракты,
  маршрутизацию, screening и полный SDK → Go HTTP adapter на подменённом HTTP.
- Из `web/backend`: `go vet ./...`, `go test ./... -cover` с отдельной
  PostgreSQL 17, всеми миграциями и demo seed. Тестируются все 13 сервисов,
  четыре направления, выбор записи, ошибки и границы доверия.
- `just repository-check`: служебные файлы и чистота diff.

Go запускался на сервере в отдельном временном контейнере PostgreSQL, удалённом
после тестов. Производственные базы не использовались. Полный `just check`
локально остановился на отсутствии Go; frontend, race и Compose оставлены CI.
Новых зависимостей нет; CI автоматически подхватывает новые pytest и Go тесты.

## Живая LLM

Использованы ровно 6 разрешённых запросов DeepSeek, по одному на сценарий.
Текущий DirectRunner и production transport, синтетические записи из
`tools/*/demo.json`. MCP session подменена: этот прогон проверяет
формирование ответа LLM и runtime routing, а не доступность настоящих сервисов.
Профиль задавался доверенным тестовым контекстом. Предварительное чтение
контекста выполняет runtime; успешный вызов не доказывает самостоятельный выбор
инструмента моделью. Заявки, сообщения и изменения данных не выполнялись.

| Направление / вопрос | Фактический результат |
| --- | --- |
| Аналитик / доступные инструменты | Верно перечислены Mattermost, Redash, Trino, Trisigma, Jira, Confluence. В конце остался пустой заголовок «Источник:». |
| Аналитик / конверсия Redash | Верны исходные числа 1000/680/580/550 и потеря 32%, но общая конверсия 55% прямо не названа. |
| Бэкендер / ошибки Grafana | Верно: рост с 1% до 3% после версии 1.8.4. |
| Тестировщик / результаты TMS | Верно: непройденный кейс отсутствующего отчёта, VIN DEMO-VIN-017, AUTO-1. |
| Дизайнер / макет Figma | Верно: подтверждение участия #яПомогаю, версия 3, два комментария. |
| Аналитик / запуск Trino | Агент сообщил, что запуск недоступен, и показал сохранённые данные. |

Все шесть ответов прошли структурные проверки runtime. После прогона промпт
дополнен требованиями отвечать конкретной метрикой и не писать отдельный
заголовок источников. Эти две правки живой LLM повторно не проверялись:
разрешённый бюджет исчерпан. Это небольшая проверка интеграции, не оценка
стабильности качества или общего golden-набора.
