# Браузерное расширение

В [apps/extension](../../apps/extension/) зафиксированы React и типы Chrome API. Для прототипа используем Chromium Manifest V3, а TypeScript и Vite берём из корневого npm workspace. [Манифест зависимостей](../../apps/extension/package.json), [Manifest V3](https://developer.chrome.com/docs/extensions/develop/migrate/what-is-mv3)

Расширение даёт popup с быстрым вопросом о текущей вкладке. В текущем фронтенд-прототипе `src/context.ts` проверяет адрес тестовой страницы и показывает локальную подсказку. Backend не вызывается. После подключения API этот adapter можно заменить вызовом Go по контракту OpenAPI.

### Карта расширения

- `src/main.tsx` — popup, поле вопроса, состояние ожидания, ответ и переход в веб-приложение.
- `src/context.ts` — безопасное сопоставление URL с одной поддерживаемой demo-страницей.
- `src/styles.css` — компактная версия палитры и motion-принципов веб-приложения.
- `public/manifest.json` — Manifest V3 с минимальным `activeTab` разрешением.

Сборка выполняется командой `npm run build --workspace=@ai-buddy/extension`. При другом адресе веб-прототипа скопируй [`.env.example`](../../apps/extension/.env.example) в `.env` и укажи `VITE_WEB_URL`. Каталог `apps/extension/dist/` загружается в Chromium через страницу расширений в режиме разработчика.

Для интерфейса питомца и быстрых вопросов придерживайся [правил оформления веба](web.md#дизайн-и-компоненты). При реализации зафиксируй поддерживаемые браузеры и страницы, манифест и разрешения, точки входа, правила отбора контекста и команды сборки, установки и проверки.
