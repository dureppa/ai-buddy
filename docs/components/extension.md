# Браузерное расширение

Каталог [apps/extension](../../apps/extension/) сейчас содержит `.gitkeep`.

Расширение даст быстрый доступ к питомцу на поддерживаемых страницах. Стажёр сможет перейти в веб-приложение или задать вопрос о текущей странице. Для ответа расширение передаст относящийся к вопросу контекст в Go API.

При реализации обновляйте этот документ. Укажите поддерживаемые браузеры и страницы, манифест и разрешения, точки входа, правила отбора контекста, а также команды сборки, установки и проверки.
