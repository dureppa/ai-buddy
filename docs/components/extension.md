# Браузерное расширение

В [apps/extension](../../apps/extension/) зафиксированы React и типы Chrome API. Для прототипа используем Chromium Manifest V3, а TypeScript и Vite берём из корневого npm workspace. [Манифест зависимостей](../../apps/extension/package.json), [Manifest V3](https://developer.chrome.com/docs/extensions/develop/migrate/what-is-mv3)

Расширение даст быстрый доступ к питомцу на поддерживаемых страницах. Стажёр сможет перейти в веб-приложение или задать вопрос о текущей странице. Для ответа расширение передаст относящийся к вопросу контекст в Go API.

Для интерфейса питомца и быстрых вопросов придерживайся [правил оформления веба](web.md#дизайн-и-компоненты). При реализации зафиксируй поддерживаемые браузеры и страницы, манифест и разрешения, точки входа, правила отбора контекста и команды сборки, установки и проверки.
