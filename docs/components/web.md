# Веб-приложение

Каталог [apps/web](../../apps/web/) сейчас содержит `.gitkeep`. Планируемый стек — React и TypeScript.

Веб-приложение покажет чек-лист, текущий шаг адаптации, заявки и напоминания. В чате стажёр сможет задать вопрос и увидеть состояние ожидания, результат или ошибку. Данные и действия идут через Go API.

При реализации обновляйте этот документ. Укажите точку входа, карту экранов и компонентов, расположение API-клиента и тестов, а также команды запуска и проверки.
