# Веб-приложение

В [apps/web](../../apps/web/) зафиксированы React, React Router, TanStack Query и Zod. Общие TypeScript и Vite подключены в корневом npm workspace. [Манифест веба](../../apps/web/package.json), [версии и установка](../stack.md)

Веб-приложение покажет чек-лист, текущий шаг адаптации, заявки и напоминания. В чате стажёр сможет задать вопрос и увидеть состояние ожидания, результат или ошибку. Данные и действия идут через Go API.

## Дизайн и компоненты

1. Начни с веб-библиотеки дизайн-системы Авито в Figma, если её предоставили организаторы. Бери согласованные цвета, типографику, отступы и варианты компонентов из веб-спецификаций. [Устройство Figma-библиотеки Авито](https://habr.com/ru/companies/avito/articles/543450/)
2. Как справочный макет используй Avito UI’23 из опубликованного дизайн-челленджа. Figma вернула 403 в рабочей среде. При отсутствии доступа ориентируйся на опубликованные примеры веб-компонентов и собирай макеты проекта в Figma. [Публикация AvitoTech](https://t.me/s/avitotech?after=1671), [UI-кит Avito UI’23](https://www.figma.com/file/5w7rTOCKS7wIs5l7xrKFfY/Avito-UI%E2%80%9923?node-id=0%3A1)
3. Реализуй повторяющиеся кнопки, поля ввода, карточки, списки и диалоги как общие React-компоненты веба. Вынеси значения цвета, типографики и отступов в общие токены CSS. Согласуй названия и состояния с макетами. Для форм и чата опиши состояния ожидания, ошибки, успеха и пустого списка. [Спецификации и состояния в дизайн-системе Авито](https://habr.com/ru/companies/avito/articles/543450/)

При реализации обновляй этот документ. Укажи точку входа, карту экранов и компонентов, расположение API-клиента и тестов, ссылку на макеты и команды запуска и проверки.
