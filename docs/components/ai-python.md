# Python-сервис AI Buddy

В [services/ai-python](../../services/ai-python/) зафиксированы Python 3.13, Flask и клиент MCP. Ruff, mypy, pytest и pytest-cov входят в dev-зависимости. Для локальной работы используй `uv sync --locked` и `uv run --locked` из каталога сервиса. [pyproject.toml](../../services/ai-python/pyproject.toml), [uv.lock](../../services/ai-python/uv.lock)

Сервис примет сообщение и контекст от Go, сформирует запрос к модели и при необходимости вызовет инструмент. Он обработает недоступность модели или инструмента и вернёт результат в Go-бэкенд. Права на бизнес-операции проверяет Go.

Выбор LLM и настройку её API зафиксируй при реализации. Обнови этот документ с указанием точки входа, расположения промптов и спецификаций, клиентов LLM и MCP, обработки ошибок, конфигурации и команд запуска и тестов.
