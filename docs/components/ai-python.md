# Python-сервис AI Buddy

Каталог [services/ai-python](../../services/ai-python/) сейчас содержит `.gitkeep`. Планируемый стек — Python и Flask с подключением LLM через API и инструментов через MCP.

Сервис примет сообщение и контекст от Go, сформирует запрос к модели и при необходимости вызовет инструмент. Он обработает недоступность модели или инструмента и вернёт результат в Go-бэкенд. Права на бизнес-операции проверяет Go.

При реализации обновляйте этот документ. Укажите точку входа, расположение промптов и спецификаций, клиенты LLM и MCP, обработку ошибок, конфигурацию и команды запуска и тестов.
