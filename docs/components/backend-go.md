# Go-бэкенд

В [services/backend-go](../../services/backend-go/) заданы версия Go и зависимости pgx/v5 и MCP Go SDK. Публичный HTTP/JSON API планируется на стандартном `net/http`, контракты описываются в OpenAPI. [go.mod](../../services/backend-go/go.mod), [go.sum](../../services/backend-go/go.sum), [стек проекта](../stack.md)

Go-бэкенд предоставит API веб-приложению и расширению, проверит права пользователя и выполнит бизнес-операции. Корпоративные сервисы будут имитироваться. Бэкенд будет хранить заявки и прогресс адаптации и возвращать результат операции клиенту или AI Buddy.

При реализации сохраняй раздельную ответственность HTTP-обработчиков, бизнес-операций и доступа к данным. Проверяй входные данные на границе API, передавай контекст запроса в PostgreSQL и другие сервисы. В этом документе укажи точку входа, пакеты, миграции, контракты инструментов и команды запуска и тестов.
