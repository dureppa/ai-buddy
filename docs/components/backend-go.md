# Go-бэкенд

Каталог [services/backend-go](../../services/backend-go/) сейчас содержит `.gitkeep`. Планируемый стек — Go и PostgreSQL. Действия для Python-сервиса планируется открыть через MCP.

Go-бэкенд предоставит API веб-приложению и расширению, проверит права пользователя и выполнит бизнес-операции. Корпоративные сервисы будут имитироваться. Бэкенд будет хранить заявки и прогресс адаптации и возвращать результат операции клиенту или AI Buddy.

При реализации обновляйте этот документ. Укажите точку входа, пакеты API и бизнес-логики, хранилище и миграции, контракты инструментов, настройки и команды запуска и тестов.
