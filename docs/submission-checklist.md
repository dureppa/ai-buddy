# Чек-лист технической сдачи

Пункты отмечаются после проверки на версии, которую команда отправляет на хакатон. Требования кейса собраны в [материалах Авито](avito-sources.md).

- [ ] Из чистого клона по README можно установить зависимости, запустить приложение и при необходимости загрузить расширение в браузер.
- [ ] README содержит версии инструментов, способ входа под тестовыми профилями, команды запуска тестов и ссылку на [маршрут проверки](demo.md).
- [ ] Внешний AI-провайдер и модель указаны в README, когда они используются. В `.env.example` есть имена настроек и описание передачи ключа. Пример конфигурации свободен от реальных секретов.
- [ ] Синтетические данные загружаются воспроизводимо, имитация корпоративного сервиса работает в режиме демонстрации.
- [ ] Основной маршрут пройден под двумя профилями. Разрешённое действие отображает и сохраняет результат, запрещённое оставляет состояние прежним.
- [ ] SDD-спецификации совпадают с поведением агента и его инструментов. OpenAPI соответствует реализованным HTTP-операциям.
- [ ] Приложен воспроизводимый отчёт о покрытии строк прикладного кода **выше 80%**. Зависимости, генерация и сами тесты исключены из измерения.
- [ ] Видео показывает путь от запроса до результата. Ссылка или путь к видео указаны в README либо в материалах сдачи.
- [ ] Если сдаёте приватный репозиторий, проверьте доступ аккаунта жюри `hack-and-change-2026`.
