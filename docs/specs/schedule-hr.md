# Данные HR в расписании

Личные события при включённом API хранятся в Go/PostgreSQL, доступны вебу и
агенту для чтения периода и создания с подтверждением. [Календарь](agent-calendar.md).
Это дополняет, а не заменяет описанную ниже HR-сводку за сегодня.

Личные события различаются цветом по типу: созвон — синий, встреча — зелёный,
напоминание — фиолетовый. Цвет одинаков в недельном календаре и ближайших
событиях главной. Он назначается при создании и меняется вместе с типом при
редактировании. Ранее сохранённые события получают цвет своего типа при чтении,
без потери названия, даты и описания. Учебные встречи также зелёные.

Главная и «События» показывают отпуска, чьи даты включают текущий день, и командировки с выездом сегодня. День определяется по Москве. Заявки на согласовании помечаются своим статусом. Записи редактируются в исходном сервисе. Отказ одного сервиса не скрывает личные встречи и записи другого сервиса.

Чат Buddy получает те же сведения для вопросов о сегодняшнем дне, отпуске и командировке. Сервер определяет профиль по сессии и передаёт модели только строки за сегодня и состояние источников. Корпоративные мероприятия в отдельном каталоге пока не содержат дат.
