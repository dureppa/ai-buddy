# Демосессия AI Buddy

Стартовая страница `/` предлагает три синтетических профиля при отсутствии активной сессии. После выбора AI Buddy сохраняет ID активного профиля в браузере и открывает его рабочее пространство. Перезагрузка, навигация и открытие второй вкладки сохраняют текущий аккаунт. Прямой переход на закрытую страницу без сессии ведёт на стартовый экран. Посещение стартового URL во время сессии возвращает на главную.

Настройки показывают текущий аккаунт и действие «Выйти из аккаунта». Выход завершает демосессию во всех вкладках того же браузера и открывает стартовую страницу. Данные онбординга остаются сохранёнными отдельно для каждого профиля. Идентификаторы, которых нет среди демопрофилей, считаются отсутствующей сессией. Параметры URL не меняют аккаунт.

Сессия относится к фронтенд-демо AI Buddy. Для сквозного входа во внешние корпоративные сервисы нужен общий серверный провайдер входа. Внешняя ссылка содержит адрес сервиса, а аккаунт будущий сервис определяет по своей серверной сессии после входа у общего провайдера.
