# Рабочие инструменты направлений через агента

Агент получает каталог текущего стажёра и читает актуальные записи через Go и
API самостоятельных сервисов. get_work_tools возвращает все 13 рабочих
инструментов и Jira/Confluence (если настроены).
get_work_tool_context(service, record_id?) читает один из 13 рабочих сервисов,
при необходимости одну выбранную запись. Все 13 сервисов имеют учебные записи
для каждого из четырёх продуктов; каталог агента содержит тот же набор, что UI.
Профиль/команда берутся из проверенной
делегации Go; в аргументах их нет. Чужие и неизвестные инструменты/записи — NOT_FOUND.

Аналитик: Redash, Trino, Trisigma. Бэкендер: Bitbucket, PaaS, Grafana.
Тестировщик: TMS, Postman, стенд Автотеки. Дизайнер: Figma, дизайн-система,
дизайн-ревью. Mattermost — общий. Jira и Confluence используют прежние инструменты.

Каталог сообщает настроенные возможности, не обещает здоровье сервисов.
Чтение использует только API выбранного сервиса и не подменяет сбой фикстурами.
Ответ ограничен текущим вопросом; записи возвращаются с источниками-якорями.
Списки/длинные поля ограничены с has_more/truncated; объём до 12 KiB до
дублирования JSON в MCP. Идентичность результата проверяется в Go; контент
по-прежнему проходит screening Python, команды из записей не выполняются.

Это принятая [граница MVP](../mvp.md#ограничения-mvp): интеграция 13 рабочих
сервисов через агента ограничена чтением.

Новые сервисы имеют только GET API. Запуск SQL/Postman, отметки прогонов/ревью
и сообщения в их UI пока локальные: агент может прочитать данные и дать ссылку,
но не заявляет об исполнении или сохранении таких действий. Смена Jira и заявки
используют существующие контракты и подтверждения. Новых бизнес-записей нет.

Максимум MCP grants становится 13, бюджеты остаются 3 LLM / 6 tools.
INVALID_ARGUMENTS/NOT_FOUND/FORBIDDEN новых чтений дают уточнение, а не успех;
транспортные/форматные ошибки сохраняются. local_demo остаётся с двумя tools.
Поиск знаний сохраняется для инструкций; профильные данные читаются явным tool.

Проверки: четыре каталога, все 13 сервисов, выбор записи, чужая команда и
подмена профиля/URL; неверные аргументы, сбой/redirect/oversize/некорректный
ответ, чужой team в ответе; MCP SDK → Go HTTP, screening, источники и выбор
инструмента без утечки других направлений. Платные LLM проверки — отдельно.


### Сопоставление рабочих записей и инструкций

Для вопроса о методике работы или сопоставлении нескольких инструментов
к чтению рабочей записи добавляется `search_knowledge` с выдачей до пяти
источников. Это позволяет сопоставить текущие учебные записи с инструкцией
Confluence. Простой вопрос о содержимом инструмента сохраняет прямое чтение.
Ссылки формируются из идентификаторов, полученных в этом запросе.
