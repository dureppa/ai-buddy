# Инструменты стажёра

На странице `/tools` и в навигации отображается название «Инструменты». В
сетке сначала идут три рабочих инструмента профиля, затем Jira, Confluence
и Mattermost. Глобальный поиск использует тот же список.

| Профиль | Рабочие инструменты |
| --- | --- |
| Оля | Redash, витрина заказов SQL / Trino, Trisigma |
| Саша | Bitbucket, PaaS, Grafana |
| Тимур | Тест-кейсы TMS, Postman, тестовый стенд Автотеки |
| Маша | Figma, дизайн-система Авито, дизайн-ревью |

Jira и Confluence открываются в новой вкладке с текущим профилем. Для остальных
инструментов карточка открывает инструкцию по нужному ресурсу. При отсутствии
проверенного адреса команда находит ресурс по инструкции. Старая ссылка на
инструмент другой роли открывает каталог текущего профиля.

Страница не показывает статусы прав, фильтры заявок и действия по доступам.
В кабинетах наставника и руководителя есть чек-листы и материалы стажёров.
Стажёр использует отдельный портал для своих заявок. Согласование руководителем
выключено в интерфейсе портала и API: создать и прочитать свою заявку можно,
отменить — пока она в статусе `submitted`. Попытка одобрить или отклонить
заявку возвращает `400`, запрос чужой заявки на отмену — `404`. Прежние решения
остаются в истории автора.
