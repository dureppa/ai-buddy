# Опросы стажировки

В «Моей адаптации» у каждого стажёра есть анкеты первой недели, экватора и выпуска. Карточка открывает форму с одним вопросом за шаг. Назад можно вернуться без потери ответов. Общие вопросы оценивают поддержку наставника, HR BP и AI Buddy и частоту работы с Buddy. Дополнительные вопросы зависят от этапа.

Ответы отправляются только по нажатию «Отправить ответы». Go определяет стажёра по сессии, проверяет обязательные ответы и сохраняет первую успешную отправку для пары стажёр и этап. Повтор запроса возвращает успех с сохранённой первой отправкой. Текстовый комментарий необязателен, до 1000 символов. При ошибке форма сохраняет ответы для повтора. После успеха чек-лист отмечает анкету выполненной и показывает подтверждение. Ответы не отображаются другим профилям. В режиме веба без API ответы хранятся в браузере.

В демо напоминание соответствует этапу профиля. Оно открывает ту же форму, что и чек-лист. При открытии списка показанные уведомления отмечаются прочитанными. Прочитанное напоминание остаётся доступным до отправки анкеты. Доступ к уведомлениям и отметкам ограничен текущим профилем.

После успешной отправки у карточки опроса появляются зелёная галочка и статус «Выполнено», в том числе после перезагрузки. До отправки и при ошибке сохранения индикатор остаётся пустым, включая наведение. Галочка опроса служит только индикатором: отметить или снять её вручную нельзя.
