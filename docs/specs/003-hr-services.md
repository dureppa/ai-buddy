# Демонстрационные HR-сервисы

В разделе «Корпоративные сервисы» и поиске AI Buddy доступны ссылки на шесть самостоятельных сайтов. Каждый сайт показывает один сервис, собственный синтетический демопрофиль и историю действий на своём origin.

| Сервис | Действие и проверки |
| --- | --- |
| Отсутствия | Выбрать период отпуска в календаре. Проверяются минимальный срок подачи, пересечения с записями и остаток календарных дней. |
| Командировки | Выбрать город и дату, указать смету. Проверяются право на поездку, срок подачи, открытая заявка и лимит сметы. |
| Найм | Порекомендовать кандидата на открытую вакансию. Проверяются лимит рекомендаций, формат имени и почты, а также повторная рекомендация на ту же вакансию. |
| Увольнения | Отметить шаги подготовки и сохранить черновик завершения работы. Проверяются обязательные шаги, срок уведомления и наличие черновика. Черновик остаётся в демо. |
| Согласия | Предоставить или отозвать согласие для выбранной цели. Обязательное для работы согласие отображается отдельно от двух управляемых. Повтор операции с тем же состоянием не создаёт запись. |
| Бенефиты | Запросить компенсацию на доступную программу. Проверяются право участия, остаток бюджета и повторная заявка на программу. |

Успешное действие обновляет историю и рассчитанные лимиты. При ошибке страница показывает причину, состояние сохраняет предыдущие значения. История действий хранится локально на сайте и доступна после перезагрузки. Настройки профилей описаны в JSON-фикстуре, а в интерфейсе используется фиксированный демопрофиль. При серверной интеграции сайт и инструмент агента должны читать и обновлять данные через API соответствующего сервиса.
