# Учебные сервисы рабочих инструментов

На страницах рабочих сервисов нет ссылки возврата в каталог «Инструменты».
При ошибке загрузки доступна кнопка «Повторить».

Jira и Confluence используют существующие контракты. Остальные 13 карточек
открывают самостоятельные страницы /work-tools/{service}, читающие
GET /api/v1/work-tools/{service}. Сессия определяет роль и команду.
У каждого инструмента отдельная PostgreSQL БД с синтетическими записями.
Сотрудник читает только записи своей команды. Неизвестный или недоступный
инструмент возвращает 404. Ошибка хранилища возвращает 503.

Общие идентификаторы связывают записи в пользовательских сценариях: DEL-1,
TRV-1, AUTO-1, HELP-1. Данные API содержат заголовок, состояние, описание,
поля и ссылку на запись. Повторный запуск добавляет недостающие учебные записи.

В Docker Compose учебный каталог включён по умолчанию. Для запуска Go вне
Compose нужно задать WORK_TOOLS_ENABLED=true и DEMO_MODE=true. При первом
запуске пользователь PostgreSQL должен уметь создавать базы buddy_tool_*.
Карточки открывают страницы при VITE_API_ENABLED=true. Агент получает
подходящие записи при поиске по названию инструмента или воронке через
существующий MCP search_knowledge и ссылается на запись по якорю.

Confluence в этом режиме читает отдельную buddy_tool_confluence. При старте
страницы прежней базы копируются с сохранением идентификаторов и версий.
Jira читается по JIRA_API_URL через её собственный API назначенных задач,
ссылки используют JIRA_PUBLIC_URL. Запуск с Jira: docker compose --profile hr
--profile jira up --build.

Рабочие области показывают записи в контексте продукта: дашборды и эксперименты,
репозиторий и релизы, тестовые прогоны и запросы, холст и ревью, каналы команды.
Поиск фильтрует список в текущем инструменте. Якорь открывает запись напрямую.
Сохранённый запрос Trino показывает учебную выборку; запрос Postman читает
соответствующие фикстуры стенда. Неизвестный VIN показывает отсутствие фикстуры,
а недоступный API — ошибку с повтором. Отметки прогона, ревью и сообщения в
учебном интерфейсе действуют, пока открыта запись.
