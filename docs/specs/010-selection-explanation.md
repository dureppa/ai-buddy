# «Уточнить у агента» по выделенному тексту

## Сценарий

В AI Buddy и подключённых корпоративных сервисах стажёр выделяет текст.
Рядом появляется кнопка «Уточнить у агента». До нажатия сеть не вызывается.
По нажатию открывается боковая панель рядом с текущей страницей: цитата,
название задачи/материала, ожидание, ответ и поле уточнения. Выделение сохраняется
при клике. Кнопка работает с мышью и клавиатурой; Escape закрывает панель.
В узком окне панель занимает доступную ширину. Модальные карточки задач и
сервисов поддержаны, включая native dialog. Текст полей ввода, редактируемых
областей и самой панели не отправляется. Фрагмент — до 1200 символов;
более длинный фрагмент предлагается сократить без скрытого усечения.

Ответ — до трёх коротких пунктов: что означает фрагмент, зачем он нужен и
как связан с текущей задачей/материалом. Источники отдельными карточками.
Уточнения продолжают тот же диалог с тем же контекстом. Новый фрагмент
создаёт новый диалог. Ответ старого запроса после смены фрагмента, профиля
или закрытия панели не появляется в новом состоянии.

## Контекст и границы

POST /api/v1/chat/messages получает page_context.url (как прежде очищенный
от query/fragment) и необязательный selection: text, title и resource.
resource: kind=task|confluence|work_tool|jira|service, id, service, label,
description, page_ids (до трёх прикреплённых страниц Confluence для task); поля ограничены и проверяются на обеих серверных границах.
Заголовок — до 200, описание локального пункта — до 800, id — до 128 символов.
У work_tool service из 13 разрешённых; у service — идентификатор HR/доступов.
Идентификатор страницы Confluence/задачи Jira передаётся отдельно от URL.
Доступ определяется серверной сессией, не полями выделения или DOM.

Передаётся только фрагмент и ближайший явно размеченный контекст задачи или
записи. Полный DOM, поля форм, файлы и произвольные query-параметры не читаются.
Локальный пункт чек-листа не объявляется серверным заданием: его название и
описание — непроверенный пользовательский контекст. В этом режиме инструменты
серверного task_context/task_evidence для локального пункта не объявляются. Совпадение текста не
подтверждает завершение задачи или существование связи между сервисами.
Прикреплённые ссылки распознаются только для настроенного Confluence; передаются
идентификаторы страниц, а не произвольные адреса для загрузки. Файлы не читаются.
Выделение и название сохраняются с вопросом в истории отдельного диалога.

Confluence читается get_knowledge_page, запись рабочего инструмента —
get_work_tool_context, Jira — get_service_context; поиск инструкций и связанных
материалов — search_knowledge. Связи называются только по прочитанным данным.
При отсутствии материалов допускается явно обозначенное общее объяснение
термина, без выдуманных правил компании, персонального прогресса и ссылок.
Пустой вспомогательный поиск сохраняется в аудите, но не передаётся модели как
доказательство отсутствия данных уже прочитанной записи.
Обычный чат сохраняет прежнюю проверку пустых источников. Ошибка доступа
или исключённый источник не выдаются за прочитанный документ.

Режим пояснения разрешает только чтение. Python не публикует write-tools;
Go подписывает признак read_only в delegation/resource JWT и запрещает
submit_access_request/prepare_service_action для такой делегации. Выделенные
команды не запускаются. Текст и метаданные считаются недоверенными, проходят
screening и не повышают привилегии. Ограничения MVP из SDD 009 сохраняются.

На внешних сайтах /buddy-api/ направляется в Go Buddy отдельно от собственных
API Confluence/доступов/инструментов; Vite и серверный nginx согласованы.
Сессия остаётся привязана к текущему стажёру; нового выбора профиля нет.
Без API панель сообщает о необходимости серверного режима, не имитирует LLM.

## Ошибки и проверки

Пустое/слишком длинное выделение и некорректный resource — 400.
Неподдерживаемая ссылка не загружается сервером. Чужая запись — прежний
NOT_FOUND/FORBIDDEN; недоступный MCP/API — явная ошибка с повтором.
Подозрительные команды в контексте не передаются модели как инструкции.
Повтор не меняет данные сервисов; кнопка отправки блокируется на время запроса.

Проверки: выделение/позиционирование/клавиатура/формы/native dialog;
передача контекста и отдельный разговор; ожидание, уточнение, сбой, повтор,
смена профиля/выделения; пути Buddy API на внешних сайтах; Go validation,
read_only audience/гранты, сохранение цитаты; Python чтение конкретных записей,
пустой поиск в обычном и поясняющем режимах, инъекции и блокировка write-tools.
