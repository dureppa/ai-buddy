# Явное уточнение и development агента

Агент прямо просит пользователя прислать значения недостающих обязательных параметров. Перечислить поля без просьбы недостаточно. Для отсутствия это тип, начало и окончание; примеры типов допустимы только из полученного источника. Уже названные параметры не запрашиваются повторно.

После восстановления MCP-контекста просьба сохраняется. Исправление цитаты меняет оформление источников, а не смысл ответа; агент не комментирует этот процесс пользователю и не добавляет уточнение в готовый ответ о наставнике.

Если параметры отсутствуют, prepare/submit не вызываются. Когда параметры известны, сохраняются SDD 007/008: серверные полномочия проверяет Go; prepare возвращает черновик, выполнение подтверждает человек на странице действия. Ограниченная заявка доступа может быть сохранена только при разрешении текущего turn; submitted не означает выдачу прав. Сбой MCP/LLM сохраняет прежний безопасный код, не становится подтверждением успеха. Переход этапа по-прежнему одобряет наставник.

[Development agent-v2](../../ai-agent/evals/agent-v2/README.md) версионирует синтетическое окружение отдельно от исходного agent-v1. Manifest фиксирует схемы своего snapshot, отчёт — полный текущий runtime-каталог и SHA выбранного development. Review использует ту же версию/hash. Holdout не запускается этим CLI. Fixtures не являются живыми Go API и не добавляют кнопки на сайт.

Проверки: Flask/SDK mock regression для уточнения через recovery и citation repair; отсутствие лишнего требования параметров в ремонте контакта; manifest/schema/version guards; одинаковый dataset в сохранённых DeepSeek trials. Факты и ограничения оцениваются отдельно от HTTP/schema, человеческая приёмка остаётся отдельной.
