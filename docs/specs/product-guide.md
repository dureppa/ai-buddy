# Описание команды в путеводителе

При открытии путеводителя веб отправляет POST /api/v1/product-guide/team. Go определяет команду по серверной сессии и ставит задачу только для команды без описания. Первый POST без тела и повторные POST возвращают текущее состояние. POST с retry: true повторяет только неудачную попытку. GET читает результат без запуска. Ответ содержит status (missing, pending, ready или failed) и, для ready, cards с тремя парами title и text.

Задача и результат хранятся в PostgreSQL по team_id. Воркер получает задачу с ограниченной по времени арендой. После остановки процесса задачу можно подобрать заново. Устаревшая попытка не может записать результат. Сбой или неверный формат ответа агента переводят задачу в failed.

Go отправляет доверенный бриф, название команды и продукта в POST /internal/v1/team-guide с действующим токеном AI-сервиса. Агент возвращает три карточки на русском по брифу. Продукт и Авито описаны статически и доступны при сбое генерации. В режиме без API используются карточки демо.
