# Стартовый набор ресурсов профиля

Для каждого из четырёх стажёров базовые группы «Чаты», «Доступы», «Документы»
содержат ссылки своего продукта и специальности. Один набор используется кабинетом
наставника/руководителя и стажёром; пользовательские публикации дополняют его через
существующую форму с проверкой команды. Это учебные данные. Ссылки мессенджера
ведут на настроенный VITE_MESSENGER_URL либо синтетический chat.example.
Публикации по-прежнему локальные, доступны в том же браузере; серверное хранение
и выдача их агенту этим изменением не реализуются.

Ссылка доступа содержит только id шаблона и профиль, не готовую операцию.
Портал после авторизации читает каталог своей команды, находит допустимый шаблон
и первый разрешённый ресурс, заполняет поля, минимальные права, срок 30 дней и
учебное обоснование по задаче продукта. Показывает сводку; отправка только явной
кнопкой пользователя. Недопустимый шаблон, чужой профиль, недоступный API или
неполная конфигурация не приводят к отправке и показывают ошибку/обычную форму.
Повторное обновление каталога не открывает закрытую форму заново. Реальные права
не выдаются; серверная проверка, идемпотентность и согласование сохраняются.
