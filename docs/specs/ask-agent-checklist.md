# Разбор пункта адаптации в панели Buddy

## Вход и ответ

У пункта на главной и в «Моей адаптации» есть кнопка «Разобрать пункт».
Она открывает общую боковую панель Buddy на текущей странице и отправляет
один вопрос о выбранном пункте. Checkbox и прогресс не меняются. В панели
видны название пункта, краткий разбор смысла/назначения, шаги выполнения и
карточки нужных материалов или страниц сервисов. Повторный клик во время
ожидания не дублирует запрос; новый пункт заменяет контекст.

«Спросить Buddy» в блоке помощи и плавающая кнопка открывают ту же панель
в общем режиме, без автоматической отправки вопроса. Полный чат доступен
из навигации и по явной ссылке «Открыть полный чат» в панели.
История и ожидание ответа общие. Переход между панелью и полным чатом сохраняет
контекст пункта и уточнения. Контекст виден пользователю и снимается кнопкой
«Общий вопрос»; общий вход через Buddy также снимает его.

Название, описание, owner и до трёх прикреплённых Confluence page_ids передаются
через page_context.selection во всех уточнениях, пока выбран пункт. Личность
берётся из сессии. Это локальный пункт, его id не используется как серверный
task_id. Разбор разрешает только чтение; не создаёт заявки и не завершает пункт.

## Материалы и ошибки

Агент читает прикреплённые страницы, команду, каталог инструментов и поиск.
Ссылки показываются на реально прочитанные материалы и известные доступные
страницы сервисов. Используется общий рендерер источников с исправлениями SDD 011.
Источник без подходящего назначения не подменяется другой страницей.
Если материала нет или прав недостаточно, агент сообщает конкретный пробел.

При API-ошибке в панели видна ошибка и повтор того же запроса с тем же контекстом.
Ответ сервера не подменяется демонстрационным. При смене профиля поздний ответ
не появляется у другого стажёра. После перезагрузки сохраняется серверная
история; локальный активный контекст без явного выбора не восстанавливается.
В режиме без API ответ явно учебный, получен из локального описания пункта.

Универсальные кнопка выделения текста и отдельная панель SelectionAssistant
удалены из Buddy и корпоративных сайтов. Схема selection, проверка прав,
подписанный read_only и чтение Confluence остаются механизмом разбора пункта.
Расширение браузера этим изменением не затрагивается.

## Проверки

Оба общих входа открывают одну панель; «Разобрать пункт» сохраняет текущий URL,
передаёт контекст и не меняет отметку. История/ожидание/контекст общие с полным
чатом. Уточнение, повтор ошибки, смена пункта, общий режим и смена профиля
проверяются отдельно. Источники сохраняют адреса Confluence/сервиса/инструкции.
Выделение обычного текста больше не показывает отдельную кнопку.
