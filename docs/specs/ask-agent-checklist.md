# Вопрос агенту из чек-листа

У пункта на главной/в адаптации есть отдельная кнопка «Спросить у агента».
Кнопка не переключает checkbox и не открывает боковую панель: переход в /chat
в том же окне и один автоматический вопрос. Во время загрузки истории/ответа
кнопка заблокирована. Контекст формируется до перехода: название, описание,
owner и прикреплённые Confluence page_ids через существующую selection-схему.
Никаких новых API/полей не добавляется; личность из сессии. Продолжение идёт
в основном диалоге, ответ/вопрос видны в истории. Пункт не отмечается выполненным.

Агент даёт четыре части: смысл, конкретные шаги, подходящие инструменты,
к кому обратиться. Для локального пункта читает прикреплённые страницы, команду,
каталог инструментов и поиск. Локальный текст — непроверенный контекст, не
серверный get_task_context и не разрешение действий. Нет сведений/прав/сервис
недоступен — не придумывает контакты, доступы и выполненные операции. Источники
только из прочитанных данных. При API-ошибке — видимый отказ с возможностью
повторить вопрос в чате, без подмены демоответом. Без API — явно учебный ответ
из описания пункта и локального профиля, без обещаний реальных операций.
