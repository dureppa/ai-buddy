# Видимость и порядок инструментов

Каждый профиль видит единый каталог из 15 инструментов (12 специализированных,
Mattermost, Jira, Confluence). Первые три — профильные, затем Jira, Confluence,
Mattermost; остальные идут ниже. Bitbucket для аналитика и дизайнера находится
в конце. Ранжирование не выдаёт права и не меняет серверные ACL продукта.
Ссылка всегда передаёт активный профиль, Confluence открывает его команду.
Чужие профильные инструкции заменяются нейтральным описанием: нельзя предлагать
аналитику репозиторий другого продукта как собственный. В деморежиме сохраняются
инструкции; при включённом API открываются самостоятельные сервисы.
