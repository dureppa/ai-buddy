# Противоречащие инструкции

Если разные инструкции дают несовместимые указания для одной ситуации,
Buddy кратко описывает расхождение, пересказывает каждое указание со своей
ссылкой и предлагает уточнить порядок у наставника. Различия в области применения
или последовательные шаги сами по себе не считаются конфликтом. При расхождении
Buddy не рекомендует один из вариантов и не готовит действие по спорному правилу.

Агент сравнивает только материалы, полученные для текущего профиля и допущенные
к ответу. Права определяет сервис поиска. Ссылки проходят действующую проверку
источников, а интерфейс показывает соответствующие карточки. Вопрос об инструкции
не инициирует операцию. Если поиск вернул ошибку или недостаточно данных,
действует обычная обработка отсутствия сведений.

Распознавание различий в свободном тексте выполняет LLM. Автоматическая проверка
ссылок подтверждает их происхождение. Семантическую точность проверяет отдельный
сценарий с живой моделью.
